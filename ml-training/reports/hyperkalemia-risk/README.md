# Sri Lankan longitudinal hyperkalemia research model

Target: next pre-HD potassium >= 5.5 mmol/L within 14–62 days.

Validation ROC-AUC: 0.7636; validation PR-AUC: 0.5248.
Held-out test ROC-AUC: 0.6617; test PR-AUC: 0.2623.

This is internal retrospective research evaluation only. The returned probability is not clinically calibrated and must not be used as an autonomous diagnosis or treatment decision.
