# AI Risk Stratification Implementation

Feature:
AI-based patient risk assessment and abnormal laboratory alert support.

Implemented v1:
- Working, explainable adult deterioration scoring engine.
- Persistent hospital-scoped assessments and clinical review workflow.
- Live dashboard for observations, optional CBC values, alerts and contributing factors.

The demo database is not labelled training data. V1 therefore uses transparent clinical rules instead of pretending an untrained model is validated. A fitted ML model requires representative anonymized data, external validation, calibration, governance approval and clinical safety review.
