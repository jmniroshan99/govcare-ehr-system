# Calculations and threshold reference table

Rules are saved under `GOVCARE-CLINICAL-RULES-2.0`. [The exported registry](../../verification/clinical-intelligence-v2/rule-registry.json) includes output meaning, population, required inputs, units, formula, missing-data policy, validation status and test identity. Model definitions, parameters, target, artifacts and validation metrics are in the separate versioned [research registry](../../ml-training/model_registry/cdss-20261020-clinical-review.json) and serving artifact metadata. No local nephrologist approval is assumed.

| Output | Adopted calculation or boundaries | Applicability / limitations | Primary reference |
|---|---|---|---|
| Recorded potassium severity, mmol/L | Low: severe `<2.5`; moderate `[2.5,3.0)`; mild `[3.0,3.5)`. High: mild `[5.5,6.0)`; moderate `[6.0,6.5)`; severe `>=6.5`. Values use full precision before display rounding. | Adult reference review. Between 3.5 and 5.5 means outside the adopted abnormal bands, not guaranteed normal/safe. Unknown dates, sample quality and dialysis timing remain explicit. Severe bands trigger source verification and review, with no automatic treatment. The continuous low-band endpoints make the source's decimal reporting convention explicit. | [NHS SPS hypokalaemia](https://www.sps.nhs.uk/articles/hypokalaemia/); [UK Kidney Association hyperkalaemia guideline, 2023](https://www.ukkidney.org/sites/default/files/FINAL%20VERSION%20-%20UKKA%20CLINICAL%20PRACTICE%20GUIDELINE%20-%20MANAGEMENT%20OF%20HYPERKALAEMIA%20IN%20ADULTS%20-%20191223.pdf) |
| Adult Hb reference comparison, g/dL | Male `<13`; female `<12`; equality is not below threshold. | Requires recorded adult age and sex. Missing population context withholds classification. CBC, reticulocytes, ferritin and TSAT support evaluation; Hb alone cannot identify iron deficiency or treatment need. **[Confirm with the nephrologist]** pregnancy, pediatrics and treatment pathways. | [KDIGO 2026 anemia guideline, Appendix A and evaluation algorithms](https://kdigo.org/wp-content/uploads/2026/04/KDIGO-2026-Anemia-in-CKD-Guideline.pdf) |
| Measured URR, % | `100 × (pre − post) / pre`; `pre > 0`, `0 <= post <= pre`. Urea mg/dL is divided by 6.006 to mmol/L. | Same authorized patient/session, actual ordered collection times, explicit compatible units and verified source. BUN is not substituted. No clamping. Common `>=65%` reference is shown only for the explicitly recorded in-centre thrice-weekly regimen; individual prescription review remains necessary. | [National Kidney Foundation hemodialysis](https://www.kidney.org/kidney-topics/hemodialysis) |
| Observed creatinine change | Absolute `new − old`; percent `100 × (new − old) / old`, with positive previous value. Elapsed time uses actual timestamps. | Same patient, canonical units, comparable sampling context, distinct dated observations. A newer undated record remains separate from an earlier dated pair. One result yields “Trend not established”. No automatic progression diagnosis or long-term extrapolation. | [KDIGO 2024 CKD guideline, evaluation and progression](https://kdigo.org/wp-content/uploads/2024/03/KDIGO-2024-CKD-Guideline.pdf) |
| Acute creatinine review signal | Increase `>=0.3 mg/dL` within 48 h or ratio `>=1.5` within 7 days. | Recent comparable sources; not applied as an acute threshold in verified maintenance dialysis. Signals review only; urine output and full acute clinical context are not supplied and no AKI diagnosis/stage is inferred. | [KDIGO AKI guideline, 2012, section 2.1.1](https://kdigo.org/wp-content/uploads/2016/10/KDIGO-2012-AKI-Guideline-English.pdf), creatinine criteria retained from existing application; **[confirm with the nephrologist]** the local AKI pathway and baseline selection. |
| Provisional recorded G/A category | G1 `>=90`, G2 `[60,90)`, G3a `[45,60)`, G3b `[30,45)`, G4 `[15,30)`, G5 `<15`. A1 `<30`, A2 `[30,300]`, A3 `>300 mg/g`. Qualitative KDIGO grid. | Requires actual eGFR and urine ACR; serum albumin is not ACR. Confirm CKD chronicity. A single G1–G2/A1 result does not establish CKD. Category is not an event percentage or a measured trend. | [KDIGO 2024 CKD classification](https://kdigo.org/wp-content/uploads/2024/03/KDIGO-2024-CKD-Guideline.pdf) |
| KFRE two-/five-year treated kidney failure | `L = −0.2201(age/10−7.036) + 0.2467(male−0.5642) −0.5567(eGFR/5−7.222) +0.4510(ln(ACR)−5.137)`. `p = 1 − S0^exp(L)`; non-North-American `S0 = 0.9832` (2 y), `0.9365` (5 y). ACR mg/mmol ×8.84 → mg/g. | Existing published equation, not trained on the monthly HD file. Stable adult G3–G5, positive quantified ACR, verified context and no prior KRT/maintenance dialysis. Source pairing/recency gates still apply. Local calibration unverified. Age 18–120 is a software entry policy. | [Tangri et al., 2016](https://doi.org/10.1001/jama.2015.18202); [Major et al. supplement](https://doi.org/10.1371/journal.pmed.1002955.s008). Coefficients also cross-checked against the original-model table in [Bravo-Zúñiga et al., Table 3](https://link.springer.com/content/pdf/10.1186/s12882-025-04357-z.pdf); its Peru recalibrated models are not used. Direct retrieval of the authors' calculator JS failed certificate verification in this environment. |
| KFRE care review thresholds | Five-year `3–5%`: referral consideration; two-year `>10%`: multidisciplinary care timing; two-year `>40%`: preparation for KRT. | Distinct horizons and purposes. Other indications still apply. No treatment order or locally approved referral policy is asserted. | [KDIGO 2024, practice points 2.2.1–2.2.3](https://kdigo.org/wp-content/uploads/2024/03/KDIGO-2024-CKD-Guideline.pdf) |
| Cardiovascular surveillance | Five recorded factor groups: BP components, potassium, creatinine, age, verified diabetes status. `4/5 × 100 = 80%` coverage. | No cardiovascular event model is installed. Paired BP requires shared source/pair, matching collection time and compatible encounter. Separate components remain viewable. Unknown diabetes stays unknown. No event-risk percentage. | [KDIGO 2024 cardiovascular risk assessment](https://kdigo.org/wp-content/uploads/2024/03/KDIGO-2024-CKD-Guideline.pdf) |
| Short-horizon research outputs | Continuous next-observed Hb/URR or uncalibrated model score for next-observed pre-HD potassium `>=5.5 mmol/L`, 14–62 days. | Maintenance-HD research population, not five-year event prediction. Persisted output/explanation/model revision is used. Safety gates withhold inference for severe recorded potassium. | Project artifact metadata, actual training code and [comparison](../../ml-training/runs/cdss-20261020-clinical-review/COMPARISON.md); independent clinical validation incomplete. |
| FHIR probability semantics | Genuine specified-outcome likelihood belongs in `RiskAssessment.prediction.probability[x]` with horizon/supporting evidence. | Current uncalibrated classifier score is an explicit research extension, never a probability. Continuous forecasts use ClinicalImpression with a predicted-value extension; actual measured labs remain Observation. Saved module contracts/reviews use ClinicalImpression and Provenance. | [Official HL7 FHIR R4 RiskAssessment](https://hl7.org/fhir/R4/riskassessment.html) |

Coverage is calculated from the same `requiredInputs` array rendered in the evidence checklist. Recorded-but-invalid inputs can count as recorded while remaining unsatisfied and quality-flagged. Renal progression has exactly four requirements: current creatinine, previous comparable creatinine and their two actual collection times. URR has seven requirements, including patient/session, units and verified source. Supporting iron studies are displayed separately rather than silently changing the one-input Hb denominator.
